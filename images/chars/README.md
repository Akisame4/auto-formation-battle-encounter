# キャラ画像の置き場所

このフォルダに、キャラID.png という名前で画像ファイルを置いてください。
ファイル名は下記の通り固定（＝キャラの内部ID）。置いた瞬間、ページを再読み込みすれば
ショップカード・配置キュー・ユニット詳細パネル（全身の立ち絵）に反映されます。

| ファイル名 | キャラ |
|---|---|
| soldier.png | ソルジャー |
| guardian.png | ガーディアン |
| lancer.png | ランサー |
| archer.png | アーチャー |
| sniper.png | スナイパー |
| trapper.png | トラッパー |
| cleric.png | クレリック |
| ogre.png | オーガ |

## 盤面マーカー用の顔アップ画像（2026-09-03追加）

盤面の駒は小さい円にクリップされるため、全身の立ち絵だと何のキャラか分かりづらいという指摘を受け、
盤面マーカー（配置画面・戦闘画面とも）だけは `キャラID_face.png` という顔アップ画像を優先して使うようにしました。

| ファイル名 | キャラ |
|---|---|
| soldier_face.png | ソルジャー |
| guardian_face.png | ガーディアン |
| lancer_face.png | ランサー |
| archer_face.png | アーチャー |
| sniper_face.png | スナイパー |
| trapper_face.png | トラッパー |
| cleric_face.png | クレリック |
| ogre_face.png | オーガ |

`_face.png` が無ければ通常の全身画像（上の表）にフォールバックし、それも無ければ色付き丸＋一文字アイコンになります。

## 画像の目安
- 正方形（例: 256x256）推奨。円形にクリップして表示するので、キャラが画像の中央に来ているとよい
- 顔アップ画像は特に、顔が画像のど真ん中に来るように（マーカーは小さい円なので、少しでもズレると見切れます）
- 背景は透過でも不透明でもどちらでもOK（円の外側は自動的に切り取られる）
- ファイルが無いキャラは、今まで通りの色付き丸＋一文字アイコンで表示される（エラーにはならない）

## 別の拡張子（.jpg/.webpなど）を使いたい場合
今は `.png` 固定で読み込む実装なので、別拡張子を使いたい場合は教えてください。すぐ対応します。
